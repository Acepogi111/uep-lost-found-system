1. Report Lost Items
2. Report Found Items
3. Search Items
4. Upload Photos
5. Admin Panel for Approval
6. Claim System
7. User Login/Register

## Tech Used
- Backend: Java Spring Boot
- Frontend: HTML, CSS, Bootstrap
- Database: MySQL

## How to Run
1. Clone repo
2. Create MySQL database uep_lostfound_db
3. Update application.properties with DB username/password
4. Run LostFoundApplication.java
5. Open http://localhost:8080
